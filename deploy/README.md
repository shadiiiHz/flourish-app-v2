# دیپلوی خودکار روی سرور ابری

هر پوش به شاخه‌ی `main` (یا اجرای دستی Workflow از تب Actions) پروژه رو با GitHub Actions
روی سرور بالا می‌بره: فایل‌ها با rsync روی سرور کپی می‌شن، بعد اسکریپت `deploy/deploy.sh`
از طریق SSH روی سرور اجرا می‌شه و Node، Docker، nginx و pm2 رو (اگر نبودن) نصب می‌کنه،
دیتابیس Postgres رو با docker compose بالا میاره، دیپندنسی‌ها رو نصب و پروژه رو build می‌کنه،
migration ها رو اجرا می‌کنه و پروسه‌ها رو با pm2 (ری)استارت می‌کنه. اجرای دوباره‌ش کاملاً
بی‌خطره (idempotent) — فقط چیزهایی که وجود ندارن رو می‌سازه.

## یک‌بار قبل از اولین دیپلوی

### ۱. ساخت کلید SSH مخصوص دیپلوی (روی کامپیوتر خودت)

```bash
ssh-keygen -t ed25519 -C "flourish-deploy" -f flourish_deploy_key -N ""
```

دو فایل ساخته می‌شه: `flourish_deploy_key` (خصوصی) و `flourish_deploy_key.pub` (عمومی).

### ۲. اضافه کردن کلید عمومی به سرور

از طریق کنسول noVNC (همون که تصویرش رو فرستادی) وارد سرور شو (`ubuntu` / پسورد سرور) و:

```bash
mkdir -p ~/.ssh && chmod 700 ~/.ssh
echo "<محتوای فایل flourish_deploy_key.pub>" >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```

### ۳. اضافه کردن Secretها در گیت‌هاب

مسیر: ریپو → Settings → Secrets and variables → Actions → New repository secret

| نام | مقدار |
|---|---|
| `DEPLOY_HOST` | `37.152.187.252` |
| `DEPLOY_USER` | `ubuntu` |
| `DEPLOY_SSH_KEY` | محتوای کامل فایل `flourish_deploy_key` (کلید **خصوصی**) |
| `DEPLOY_PORT` | `22` (اختیاری، پیش‌فرض همین‌ه) |

اختیاری: زیر تب **Variables** همون صفحه، یک متغیر `DEPLOY_PATH` بساز اگه می‌خوای پروژه
جای دیگه‌ای غیر از `/home/ubuntu/flourish-app-v2` روی سرور قرار بگیره.

### ۴. باز بودن پورت ۸۰

در پنل ابر (بخش «امنیت → فایروال») مطمئن شو پورت ۸۰ (HTTP) به سمت سرور باز هست.

## اجرا

بعد از تنظیم Secretها، یک پوش به `main` بزن یا از تب **Actions** روی workflow
**Deploy** کلیک کن و **Run workflow** رو بزن. چند دقیقه طول می‌کشه (نصب اولیه سنگین‌تره).
بعدش سایت روی `http://37.152.187.252` بالاست.

اولین اجرا یک ایمیل/پسورد ادمین تصادفی می‌سازه و توی لاگ‌های Action و در فایل
`server/.env` روی سرور چاپ می‌کنه — حتماً بعد از اولین ورود عوضش کن.

برای فعال کردن پیامک (ملی‌پیامک) و درگاه پرداخت (زرین‌پال)، مقادیر مربوطه رو توی
`server/.env` روی سرور دستی پر کن (خطوط کامنت‌شده‌ی آماده اونجا هست) — این فایل توسط
دیپلوی بعدی دست‌نخورده می‌مونه.
